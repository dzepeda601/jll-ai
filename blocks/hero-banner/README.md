# hero-banner

Custom **hero** block. Purpose: Contained promo banner with a background photo and centered heading; the whole banner links to the CTA target.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: background image. Row 2: heading and a CTA link (the link makes the whole banner clickable).
