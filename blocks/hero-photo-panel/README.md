# hero-photo-panel

Custom **hero** block. Purpose: Full-bleed photo with a white rounded panel overlapping its bottom edge, holding a heading and a stacked list of chevron links (or heading + text beside a second cell such as a person card).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: image. Row 2: panel content (H2, optional paragraph, bulleted list of links). Optional second cell in row 2 sits beside the first from 900px (e.g. a person card: portrait, name, job title, link)..

## Supported variations

No variations.
