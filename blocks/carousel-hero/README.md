# carousel-hero

Custom **carousel** block. Purpose: Page-top rotating spotlight carousel: full-bleed photo slides with an overlaid heading and CTA, plus a title navigator built from the slides.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional single-cell row: navigator title (e.g. Spotlight stories). Each following row is a slide: cell 1 image; cell 2 optional short nav label paragraph, heading, description, CTA link.

No variations.
