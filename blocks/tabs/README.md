# tabs

Custom **tabs** block. Purpose: Tabs: a row of tab labels that switches between panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tab: cell 1 tab label; cell 2 panel content (paragraphs, lists, links, an optional image). Alternatively leave the block empty and follow it with sections that carry section metadata Tab ID and Tab Title (section-based tabs)..
