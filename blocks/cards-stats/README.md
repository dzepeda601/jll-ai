# cards-stats

Custom **cards** block. Purpose: Row of stat tiles: an oversized figure over a short label on a sand fill.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per stat. One cell: value paragraph (e.g. **4,100+**) then label paragraph. Or two cells: value | label..
