# tabs-stacked

Custom **tabs** block. Purpose: Expandable labelled panels laid out as a grid of full-width triggers that open one panel below. Place in the section before the panel sections; each panel section needs Tab ID and Tab Title section metadata.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Block table with only the block name (no rows needed). The following sections each carry section metadata Tab ID and Tab Title and hold the panel content (default content, cards-eyebrow).
