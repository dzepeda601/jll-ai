# accordion-divided

Custom **accordion** block. Purpose: Accordion of full-width rows separated by thin rules; optionally shows the open item's image beside the list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item: cell 1 title (question); cell 2 content (paragraphs, lists, links, optional image)..
