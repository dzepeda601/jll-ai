# hero-split

Custom **hero** block. Purpose: Page-top hero with the H1, intro and CTAs beside a large contained, rounded image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: image. Row 2: text cell (optional eyebrow paragraph, H1, intro paragraph, CTA links: bold = primary, italic = secondary). A single row with an image cell and a text cell also works..

## Supported variations

| Variation | Option class |
| --- | --- |
| Side image | `side-image` |
| Bleed | `bleed` |
| Stacked | `stacked` |
