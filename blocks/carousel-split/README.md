# carousel-split

Custom **carousel** block. Purpose: News/feature slider: one slide at a time with media on one side and a text panel (eyebrow, heading, description, CTA) on the other.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide: cell 1 image (or a link to an .mp4 with an optional poster image); cell 2 optional eyebrow paragraph, H3, description, CTA link.

## Supported variations

No variations.
