# columns-alternating

Custom **columns** block. Purpose: Zig-zag feature rows of an image beside text (eyebrow, heading, paragraph, CTA); swap the cell order per row to alternate the image side.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per feature, 2 cells: an image-only cell and a text cell (eyebrow paragraph, H2, paragraph, CTA link). Swap the cell order on alternate rows.
