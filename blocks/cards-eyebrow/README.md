# cards-eyebrow

Custom **cards** block. Purpose: Image-top link cards with an eyebrow, heading, description and an icon-only CTA; slides horizontally on small screens, three across on desktop.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: cell 1 image; cell 2 eyebrow paragraph, H3, description, link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Tiles | `tiles` |
| Links | `links` |
| Grid | `grid` |

`grid`: same rows as the default (image cell; H3, description, link) shown as image-top cards in a wrapping grid (2 across from 600px, 3 from 900px, 4 from 1200px); the whole card is the link. A card without an image gets a plain sand placeholder. Used for the services hub list.
